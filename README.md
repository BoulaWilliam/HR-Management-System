HR Management System (HRMS)

Overview

HR Management System is a web application built to simplify common HR tasks by organizing employee information, departments, and roles in one place.

The project was developed using ASP.NET MVC and SQL, following a three-tier architecture to separate the application's responsibilities and keep the code organized, maintainable, and easier to extend.

Key Features

- Employee Management: Manage and organize employee information.
- Department Management: Organize departments and their related information.
- Role Management: Manage roles within the HR system.
- Structured Architecture: Separate the application into layers for better code organization and maintainability.
- Database Integration: Store and manage HR-related data using SQL.

Technology Stack

- Backend: ASP.NET MVC
- Database: SQL
- Architecture: Three-Tier Architecture
- Version Control: Git and GitHub

Installation

#1. Clone the Repository

```bash
git clone https://github.com/BoulaWilliam/HR-Management-System.git
```

#2. Open the Project

Navigate to the cloned repository and open the solution file in Visual Studio.

#3. Configure the Database

Configure the database connection string in the application settings to match your local SQL database setup.

If the project includes a database script, execute it to create the required database and tables.

#4. Run the Application

Restore the required NuGet packages, build the solution, and run the application using Visual Studio.

Make sure the database is configured and accessible before launching the application.
